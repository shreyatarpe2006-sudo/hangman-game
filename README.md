# Hangman Game 🎮

## Description
A simple console-based Hangman game built using Python. It uses a predefined list of words and allows up to 6 incorrect guesses.

## Features
- Random word selection
- 5 predefined words
- Maximum 6 wrong guesses
- Console-based gameplay

## Technologies Used
- Python

## How to Run
1. Install Python
2. Run:
   python hangman.py
